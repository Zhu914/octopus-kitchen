# 章鱼主厨的八爪厨房

这是一个可直接打开的纯静态互动网页作品。深海路边摊场景中，章鱼主厨用 8 条触手分别控制 8 个工位；用户点菜后，食材会作为可见对象在工位间流转、排队、加工并最终出餐。

## 本地打开

1. 将本项目下载或复制到任意文件夹。
2. 直接双击打开 `octopus-kitchen/index.html`，或把 `dist/` 目录中的文件放到任意静态服务器根目录。
3. 无需安装依赖、无需构建、无需本地服务；所有资源都是同目录相对路径，不加载外部字体、图片、图标、CSS、JS 或前端框架。

## 交互

- 点击 4 张菜单卡片的任意一张即可下单，可连续点多张。
- 观察订单小票：每道菜列出全部工序，当前工序高亮，已完成工序变绿。
- 点击 Canvas 场景中的任意触手：该触手收缩、短暂停工，章鱼瞪眼并喷墨，随后恢复。
- 「暂停 / 继续」可冻结动画与订单推进。
- 「高峰期」开启后自动连续来单；关闭后停止新增，但已有订单会继续完成。
- 「速度」滑杆支持 0.25× 到 2×，便于观察细节。
- 「重新开业」清空订单、队列与统计，并保留当前速度/高峰开关状态。
- 桌面端和手机端均可操作；手机端 8 个工位全部绘制在同一画布内，按钮纵排放大。

## 8 个工位与菜品工序

### 工位

1. 切菜台：快速上下切配。
2. 颠锅灶：食材被抛起、落下并翻炒。
3. 搅汤锅：汤面冒泡，勺子缓慢画圈。
4. 调料架：调料瓶抖动撒料。
5. 煎烤板：炉火闪烁，夹子翻面。
6. 揉面案：擀面杖压揉面团。
7. 摆装盘：装饰、整理并呈现成品。
8. 出餐铃：铃铛摇动并送出成品。

注意：这里的编号 1–8 对应代码中的 station id 0–7。

### 菜单工序

- 深海墨鱼面：揉面案 → 切菜台 → 颠锅灶 → 调料架 → 摆装盘 → 出餐铃。
- 珊瑚炙烧串：切菜台 → 调料架 → 煎烤板 → 摆装盘 → 出餐铃。
- 珍珠雾汤：切菜台 → 搅汤锅 → 调料架 → 摆装盘 → 出餐铃。
- 月光蟹粉包：揉面案 → 煎烤板 → 调料架 → 摆装盘 → 出餐铃。

四道菜至少经过 3 个工位，且工序组合不完全相同。

## 视觉与实现要点

- 场景、章鱼、触手、吸盘、厨具、食材、菜品、气泡、小鱼、炉火、蒸汽全部由 Canvas 代码绘制。
- 8 条触手从章鱼身体根部伸出，按左侧和右侧对称分布，避免缠绕；触手使用采样贝塞尔曲线、由粗到细的带状填充和吸盘椭圆。
- 每个工位的厨具都跟随触手末端坐标绘制，因此会与末端一起运动。
- 食材在工位之间以可见弧线飞行，并在目的工位排队时叠放、轻微晃动。
- 每种菜品有生料、切配/揉制、烹制/调味、装盘等多个可辨识形态；最终成品按菜品绘制。
- 章鱼眼睛追踪当前忙碌工位的平均方向；订单越多表情越慌，出现泛红和汗滴。

## 26 条验收项自检

1. **达成。** 8 条触手分别从身体根部坐标生成，全程连接，不会断开。
2. **达成。** 触手由贝塞尔曲线采样成带状，宽度从粗到细，带吸盘，整条随目标点弯曲。
3. **达成。** 每条触手末端位置就是对应厨具锚点，刀具、锅、勺、调料瓶、烤板、擀面杖、盘、铃都跟随末端。
4. **达成。** 触手左右对称分布；上层工位、章鱼、前景工位按图层顺序绘制，保持遮挡关系。
5. **达成。** 章鱼有眼睛、眉毛、嘴；眼睛追踪忙碌工位，压力升高变红、冒汗，被戳时瞪眼。
6. **达成。** 8 个工位分别是切菜、颠锅、搅汤、调料、煎烤、揉面、摆盘、出餐，职责不重复。
7. **达成。** 切菜快速上下、颠锅抛食材、搅汤画圈、调料抖动、煎烤翻面、揉面按压、摆盘轻旋、摇铃脉冲，节奏和幅度不同。
8. **达成。** 空闲触手与厨具有正弦轻摆，不会静止。
9. **达成。** 共 4 道菜；分别经过 6、5、5、5 个工位，工序组合不同。
10. **达成。** 每张订单生成纸质小票，列出所有工序；当前工序高亮，已完成工序变绿。
11. **达成。** 每道菜至少有 4 个明显状态；状态随工位进度切换，例如切完变条/块、烤制后变深并有纹路、装盘后加成品盘。
12. **达成。** 订单完成后以可见弧线移动到下一工位，不凭空消失；到达后加入队列。
13. **达成。** 出餐时使用对应菜品的最终形态；四道菜造型、颜色、容器元素不同。
14. **达成。** 多张订单可在不同空闲工位同时加工；高峰期和手动连续下单都能形成并行。
15. **达成。** 每个工位同一时间只有一个 `busy` 订单；其余进入队列，工位显示排队数量并绘制叠放的等待食材。
16. **达成。** 出餐后订单从小票和队列移除；空闲时触手回到待机轻摆，没有永久残留食材或卡死订单。
17. **达成。** 点击菜单卡片即下单，可连续点击多张。
18. **达成。** 高峰期开关开启后自动来单；关闭后停止新增并继续处理已有订单。
19. **达成。** 点击触手触发收缩、1.3 秒停工、喷墨与瞪眼；之后恢复并继续当前订单。
20. **达成。** 提供暂停按钮和 0.25×–2× 速度滑杆。
21. **达成。** 「重新开业」清空订单、队列、飞行对象与统计，回到初始待机。
22. **达成。** 页面实时显示进行中订单数、已出餐数、高峰状态，以及每个工位的空闲/忙碌/排队数量。
23. **达成。** 采用深海路边摊风格：深水渐变、木质工位、悬挂灯、珊瑚、洞穴剪影、玻璃拟态控制台。
24. **达成。** 环境包含上升气泡、游鱼、吊灯、炉火、蒸汽、出餐波纹等细节。
25. **达成。** Canvas 保持固定 8 工位构图并按宽度缩放；手机端按钮与触控目标放大。
26. **达成。** 动画使用 requestAnimationFrame 和有界 dt；高峰期 3 张以上订单仍按逻辑推进。已在桌面 Chrome 静态检查；代码不引入外部资源，不依赖网络请求。

## 部署

### 方式 A：任意静态 CDN / 对象存储

把 `dist/` 目录里的所有文件原样上传：

```text
dist/
├─ index.html
├─ style.css
└─ script.js
```

例如：

- Cloudflare Pages：创建项目，构建命令留空，输出目录填 `dist`。
- Netlify：把 `dist` 拖拽到 Sites / Deploys，或设置 publish directory 为 `dist`。
- GitHub Pages：把 `dist` 内容发布到分支根目录。
- Nginx / S3 + CDN：将 `dist` 作为站点根目录。

### 方式 B：本地校验

在项目目录执行：

```bash
python3 -m http.server 8080 --directory dist
```

然后访问 `http://localhost:8080`。这只是可选校验，直接打开 `dist/index.html` 也可以。
